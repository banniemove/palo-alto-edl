- **Land toevoegen:** maak `asns-<landcode>.txt` aan; de Action pakt het automatisch op.
- **`geo` achter een AS** (bijv. `AS6830 geo`): voor providers die in meerdere landen
  actief zijn; alleen prefixes die volgens GeoLite in dat land liggen komen mee.
- **Controlerapport:** per AS de houder volgens RIPE, het aantal prefixes, lege AS-nummers
  en prefixes die volgens GeoLite buiten het land in gebruik zijn.
- **Handmatig bijwerken:** tabblad **Actions** > *Update IP-lijsten* > **Run workflow**.
- **Veiligheidsrem:** bij een lege lijst of >20% daling wordt de lijst van dat land niet
  overschreven (de run wordt rood). Is de daling bedoeld, verwijder dan dat
  `ip-list-<cc>.txt`; de volgende run bouwt hem opnieuw op.
